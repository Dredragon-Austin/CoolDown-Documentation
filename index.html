Minecraft Command Block System Documentation

This documentation describes the command block chain system for handling weapon attacks and cooldown mechanics in Minecraft 1.20.1. Follow the setup step-by-step to implement the system in your world.

Command Blocks Overview

Each command block in the chain performs a specific task. Below are the commands and their configurations:

Command Block Chain

  1. Command Block 1: 
    /scoreboard players tag @a[scores={useAttack=1..}] add attack1 {SelectedItem:{tag:{WeaponType:1b}}}

    Type: Repeat, Always Active

    Function: Tags players who use the Carrot on a Stick with the appropriate NBT data.

  2. Command Block 2: 
    /scoreboard players set @a[scores={useAttack=1..}] useAttack 0

    Type: Chain, Always Active

    Function: Resets the useAttack scoreboard.

  3. Command Block 3: 
    /item replace entity @a[tag=attack1] hotbar.0 with minecraft:diamond_hoe{Unbreakable:1b, CoolDown:5b}

    Type: Chain, Always Active

    Function: Replaces the player's Carrot on a Stick with a Diamond Hoe to enforce cooldown.

  4. Command Block 4: 
    /execute as @a[tag=attack1] run summon minecraft:lightning_bolt ~ ~ ~

    Type: Chain, Always Active

    Function: Executes the attack command (e.g., summoning a lightning bolt).

  5. Command Block 5: 
    /scoreboard players tag @a[tag=attack1] remove attack1

    Type: Chain, Always Active

    Function: Removes the attack1 tag from the player.

  6. Command Block 6: 
    /scoreboard players add @a CoolDown 5

    Type: Repeat, Always Active

    Function: Adds a cooldown score to all players.

  7. Command Block 7: 
    /item replace entity @a[scores={CoolDown=100..}] hotbar.0 with minecraft:carrot_on_a_stick{Unbreakable:1b, WeaponType:1b}
/scoreboard players set @a[scores={CoolDown=100..}] CoolDown 0

    Type: Chain, Always Active

    Function: Resets the cooldown and replaces the player's weapon back to the Carrot on a Stick.

Implementation Steps

  1. Create the necessary scoreboards using the following commands: 
    /scoreboard objectives add useAttack minecraft.used:minecraft.carrot_on_a_stick
/scoreboard objectives add CoolDown dummy
  2. Set up the command blocks in the exact order mentioned above, ensuring the appropriate block types and activation settings.
  3. Test the system by giving yourself a Carrot on a Stick with the following command: 
    /give @p minecraft:carrot_on_a_stick{Unbreakable:1b,WeaponType:1b}
  4. Right-click the item to trigger the commands and observe the effects.

Troubleshooting

If something doesn't work as expected:

  • Ensure all command blocks are configured as Always Active where required.
  • Verify the order of the chain and that each block links correctly to the next.
  • Check the scoreboard values with: 
    /scoreboard players list @p
